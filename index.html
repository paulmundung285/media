Konsep Dasar

Apa Itu Hardware dan Software?

Komputer dapat bekerja dengan baik karena adanya kerja sama antara perangkat keras dan perangkat lunak.

HARDWARE

Perangkat Keras Komputer

Hardware adalah bagian fisik komputer yang dapat dilihat dan disentuh secara langsung oleh tangan manusia.

Ciri Utama: Fisik nyata, berwujud, dan berbentuk nyata.

SOFTWARE

Perangkat Lunak Komputer

Software adalah program atau sekumpulan instruksi digital yang digunakan untuk menjalankan dan mengatur fungsi komputer.

Ciri Utama: Berupa data/program digital, tidak dapat disentuh fisik.
Hardware dan Software saling membutuhkan. Tanpa Software, Hardware tidak dapat berjalan. Tanpa Hardware, Software tidak memiliki tempat untuk beroperasi.
Bagian 1

1. Perangkat Keras (Hardware)

Perangkat keras dikelompokkan berdasarkan fungsinya dalam mengolah informasi digital.

Perangkat Input

Pintu masuk data/perintah dari pengguna ke komputer.

Pemrosesan & Penyimpanan

Mengolah data dan menyimpan informasi secara sementara.

Perangkat Output

Menampilkan atau mengeluarkan hasil pemrosesan data.

Alur Kerja Sistem Komputer:
Data Masuk (Input) → Diproses & Disimpan (Pemrosesan/RAM) → Hasil Keluar (Output).
Materi Hardware

A. Perangkat Input

Perangkat input digunakan untuk memasukkan data atau perintah ke dalam sistem komputer.

Keyboard

Memasukkan huruf, angka, dan simbol perintah ke komputer.

Mouse

Menggerakkan kursor/pointer dan memilih menu atau perintah.

Scanner

Memindai dokumen fisik atau foto menjadi bentuk gambar digital.

Mikrofon

Memasukkan suara atau rekaman audio pengguna ke komputer.

Webcam

Memasukkan rekaman gambar atau video langsung secara visual.

Materi Hardware

B. Pemrosesan & Penyimpanan Sementara

Berfungsi untuk mengolah data dan menyimpan instruksi sementara saat komputer dinyalakan.

CPU / Prosesor

Central Processing Unit

Komponen yang bertugas memproses seluruh data, melakukan perhitungan matematis, dan menjalankan instruksi program.

CPU sering disebut sebagai "Otak Komputer".

Memori / RAM

Random Access Memory

Memori cepat yang digunakan untuk menyimpan data dan program aplikasi yang sedang berjalan secara sementara.

Data bersifat sementara (hilang jika komputer dimatikan).
Materi Hardware

C. Perangkat Keluaran (Output)

Perangkat output berfungsi untuk menampilkan atau menghasilkan informasi hasil olahan komputer.

Monitor

Menampilkan visual berupa teks, gambar, video, dan antarmuka program.

Printer

Mencetak hasil dokumen atau gambar digital ke atas media kertas.

Speaker

Mengeluarkan hasil pemrosesan berupa gelombang suara atau audio.

Proyektor

Menampilkan bayangan layar komputer ke dinding/layar yang lebih besar.

Bagian 2

2. Perangkat Lunak (Software)

Software merupakan kumpulan instruksi digital yang mengontrol perangkat keras komputer.

A. Sistem Operasi

Software dasar yang mengelola seluruh sumber daya perangkat keras dan menyediakan landasan untuk aplikasi.

Pengelola Utama Komputer

B. Perangkat Lunak Aplikasi

Program yang dirancang khusus untuk membantu pengguna menyelesaikan tugas pekerjaan tertentu.

Program Pembantu Tugas
Materi Software

A. Sistem Operasi (OS)

Sistem operasi adalah perangkat lunak utama yang mengontrol kerja komputer dan mengelola hardware.

Windows

Sistem operasi paling populer pada laptop/PC.

Linux

Sistem operasi open-source yang aman dan gratis.

macOS

Sistem operasi resmi pada perangkat komputer Apple.

Android

Sistem operasi utama pada smartphone dan tablet.

iOS

Sistem operasi khusus perangkat iPhone dari Apple.

Semua contoh di atas berperan sebagai jembatan penghubung antara pengguna dan perangkat keras komputer.

Materi Software

B. Perangkat Lunak Aplikasi

Program khusus yang dibuat untuk membantu pengguna menyelesaikan tugas harian tertentu.

Microsoft Word

Digunakan untuk membuat, mengedit, dan menyusun dokumen teks.

Microsoft Excel

Digunakan untuk mengolah data angka, tabel, dan perhitungan.

Microsoft PowerPoint

Digunakan untuk membuat dan menampilkan slide presentasi.

Google Chrome

Digunakan untuk menjelajah situs web dan mencari informasi di internet.

Canva

Digunakan untuk membuat desain grafis, poster, dan materi visual.

VLC Media Player

Digunakan untuk memutar berkas multimedia video dan lagu audio.
